# Browser support

Source: https://vuetifyjs.com/en/getting-started/browser-support

## Agent Use

Use this page when you need Vuetify 4 guidance about Browser support.

## Overview

Vuetify is a progressive framework that supports all evergreen browsers.

## Key Headings

- Browsers

## Extracted Guidance

Vuetify 4 is a next generation framework that takes advantage of the latest web technology features and requires an evergreen browser to function.

This is not an exhaustive list of compatible browsers, but the main targeted ones. If you are using a browser that is not listed here, it is not officially supported.

| Browser | Version | Status | |-------------------------|:--------|----------------------------------| | Chromium (Chrome, Edge) | 119 | ✅ Supported * | | ^^ | 99 | ⚠️ Partial support ** | | Firefox | 128 | ✅ Supported * | | ^^ | 97 | ⚠️ Partial support ** | | Safari | 16.4 | ✅ Supported | | Internet Explorer | | ⛔ Not supported | | Other Browsers | | ❓ Not officially supported |

This table is updated with minor releases of Vuetify. Chrome, Firefox, and Safari will be supported at least two years back from the Vuetify x.x.0 release date. Current start date is December 2023.

Support for older browsers may be possible with additional [polyfills](https://cdnjs.cloudflare.com/polyfill/) and [PostCSS plugins](https://github.com/csstools/postcss-plugins/tree/main/plugins/postcss-logical), but has not been tested and is not guaranteed. If you need to support older browsers we recommend using Vuetify 2 or 3.
