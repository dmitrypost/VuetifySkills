# Locale providers

Source: https://vuetifyjs.com/en/components/locale-providers

## Agent Use

Use this page when implementing, configuring, or debugging the Vuetify 4 Locale providers component.

## Overview

The locale provider allows you to modify the application's current language scoped within a template

## Key Headings

- API
- Examples

## Extracted Guidance

The locale provider allows you to provide specific default prop values to components in a section of your application

| Component | Description | | - | - | | [v-locale-provider](/api/v-locale-provider/) | Primary Component |

The `v-locale-provider` expects a prop **locale** which looks the same as the **locale** object that you can pass to `createVuetify` when creating your application.
